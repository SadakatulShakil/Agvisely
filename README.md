# Agvisely

Localized weather forecasts and agricultural advisory app for the Department
of Agricultural Extension (DAE).

- **Package / bundle id:** `bd.gov.dae.agvisely`
- **Architecture:** feature-first Clean Architecture + GetX, mirrored from the
  BMD Abohawa app. Reusable *systems* are ported (theme, fonts, localization,
  network, notifications, Firebase, offline Floor DB); weather business logic
  is **not** — feature folders are scaffolded from the Figma design and left as
  TODOs.

## First-run setup

1. **Generate the platform folders** (android/ios/etc.) with the correct org —
   this wraps the existing `lib/` without touching it:
   ```bash
   flutter create . --org bd.gov.dae --project-name agvisely --platforms android,ios
   ```
2. `flutter pub get`
3. **Firebase** — create a project for `bd.gov.dae.agvisely`, then:
   ```bash
   flutterfire configure
   ```
   Drop `google-services.json` into `android/app/` and `GoogleService-Info.plist`
   into `ios/Runner/`. Then in `main.dart`, uncomment the `firebase_option.dart`
   import and pass `options: DefaultFirebaseOptions.currentPlatform`.
4. **Fonts** — put the AnekBangla `.ttf` files in `assets/fonts/` and uncomment
   the `fonts:` block in `pubspec.yaml`.
5. **Floor codegen** (only after you add/change entities):
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```
6. **API** — set the real base URL in `core/network/api_endpoints.dart`.
7. `flutter run`

## Notes

- `database.g.dart` is intentionally **not** included — it's generated by
  build_runner in step 5.
- Notification channel names and the alarm-audio `MethodChannel`
  (`bd.gov.dae.agvisely/alert_audio`) are already renamed; wire the native
  side the same way as BMD when you port the alarm-tone behaviour.
